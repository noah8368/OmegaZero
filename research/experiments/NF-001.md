## Question

Before touching chess data: do our conditional-density implementations (NSF flow, QR,
MDN) and our calibration diagnostics (PIT, coverage) correctly recover *known*
conditional distributions — and does the flow show any advantage over the baselines on
distributions with the features we expect in eval error (skew, heavy tails,
heteroscedasticity)?

This is the H0 gate: if we can't recover ground truth we know, we can't trust anything
the models say about chess positions. It also gives an early read on H2 in a controlled
setting.

## Setup

**Synthetic data generators** (`u` given a 1-D or low-D conditioner `x`), ground-truth
CDF known in closed form so PIT/coverage/quantiles have an exact reference:

1. **Heteroscedastic Gaussian.** `u | x ~ N(μ(x), σ(x)²)` with σ growing in `x` (the
   "tactical positions are noisier" analogue). Sanity floor.
2. **Conditional log-normal.** Skewed, nonnegative, heavy right tail — matches `|error|`
   shape if we ever model absolute error.
3. **Conditional bimodal mixture.** Two Gaussians whose weights/means depend on `x`.
   Tests whether QR (which needn't assume unimodality) and the flow both cope; MDN
   should nail it, single-component models should visibly fail — a good discriminator.
4. **Skew-t / heavy-tailed.** Stress the tail quantiles (95th/99th) the search actually
   uses.

**Models under test** (shared conditioner MLP where possible, for a fair fight):
- Conditional NSF (zuko) — trained by max-likelihood.
- Quantile regression — pinball loss on a fixed quantile grid; non-crossing enforced.
- Mixture density network — Gaussian/log-normal mixture, NLL loss.
- Unconditional baseline — fit ignoring `x` (floor; conditional models must beat it).

**Metrics:**
- Held-out **NLL** vs the true generator's NLL (gap → estimation error).
- **PIT** histogram + a uniformity test (KS / chi-square) against Uniform(0,1).
- **Coverage** at q ∈ {0.5, 0.8, 0.9, 0.95, 0.99}, global and stratified by `x`-bin.
- **Quantile error**: predicted vs true q-quantile across the `x` range (the number that
  matters for search).
- Wall-clock train + per-sample inference time (early read on H5 feasibility).

**Reproducibility:** fixed seeds; every generator + config behind CLI flags; single
`nf001_synthetic.py` driver that writes plots to `research/figs/NF-001/` and a metrics
table to the run dir. Record git SHA + exact command in this file on completion.
