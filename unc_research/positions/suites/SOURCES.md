# Objective sharp/quiet position suites (public domain)

Used by unc007_sharp_quiet.py for a powered P1 test (predicted spread: sharp vs quiet),
with objective labels instead of hand-eyeballed categories.

- `wac_sharp.epd` — Win At Chess "new" (300 tactical positions; best move is a tactic
  => SHARP). Source: jdart1/arasan-chess tests/wacnew.epd (Reinfeld 1958; public domain).
- `sbd_quiet.epd` — "Silent but Deadly" (134 positions whose best move is NOT a capture
  => QUIET). Source: ChrisWhittington/Chess-EPDs silent-but-deadly.epd (Dann Corbitt;
  public domain, no copyright restrictions).
